# Strata Launcher v0.1.6

适用于通过 `START-HERE.bat` 从源码安装的 Windows 版 Strata；本次针对 Strata `v0.2.3`（引擎 `0.1.48`）完成更新与校验。官方 App 和独立 Terminal 的安装方式暂不支持。

- **官方更新：**改由启动器更新脚本执行。有上游分支时只做快进拉取；没有上游时只跟随 Strata 官方最新稳定 Release，不会误拉未发布的 `main` 代码；不能快进时安全停止并保留本地改动。
- **引擎版本检查：**对照官方源码的引擎目标版本核对 `engine/BUILD.json` 与 `strata.exe --version`；旧引擎显示警告但仍可启动，缺少安装信息时提示先检查更新，避免把部分更新显示为成功。
- **模型列表刷新：**检查配置引用的 GGUF 和专家包；组件缺失的模型暂时隐藏且不删除配置，恢复文件后刷新即可重新出现；启动和切换前也会再次检查。
- **停止 Strata：**进程在确认期间已自行退出（taskkill 退出码 128）时按“已停止”处理，不再误报失败；根进程消失但 Python 服务或引擎仍在运行时会明确报错并列出剩余 PID。
- **CPU 线程数：**运行时设置新增 `--pool-workers` 入口，0 表示自动（物理核心 − 1，上限 32）；保存时写入模型配置，设为 0 恢复自动。
- **脚本编码：**修正主脚本与校准视图的 UTF-8 BOM，避免 Windows PowerShell 5.1 按 ANSI 解码中文导致乱码或解析失败。

验证：134 个 Python 测试、相关 PowerShell 测试（引擎版本、模型缺失、官方更新、CPU 线程数、分享包）、启动器环境检查和 ZIP 内容核对通过。更新与官方一词生成已在本机 Strata `v0.2.3` / 引擎 `0.1.48` 上验证；**完整日常推理尚未验收。**
