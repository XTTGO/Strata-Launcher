# Strata Launcher v0.1.8

DeepSeek 性能参数版本：把 `strata-dsv41` 的专家放置参数全部接到界面上，每一项都有说明、范围或预设；不需要看懂引擎参数也能把"内存没用满、硬盘一直在转"这类问题调对。适用于通过 `START-HERE.bat` 从源码安装的 Windows 版 Strata。本机 Strata `v0.2.4.2`、Qwen 引擎 `0.1.48`、DeepSeek 引擎 `0.1.49.2` 完成校验。

- **新增参数（DeepSeek 设置区）：** `--ssd-policy`（lru / lfu / lfu→lru）、`--mmap-experts`（auto / on / off）、`--vram-experts`（0–1）、`--dspark-block`（0–8）；`--ssd-cache` 增加 1024 GB 上限。枚举走下拉、数值走限定范围的数字框，越界或非法值不写入配置（dsv41 遇到坏参数会直接退出）。
- **互斥保护：** 选「拷进内存」（`--mmap-experts off`）时自动把 `--ssd-cache` 置 0——拷贝与内存池都会占内存，叠加等于双倍开销。
- **三个性能预设：**
  - **自动（均衡）**：全部留空，引擎自己决定（官方默认行为）。
  - **尽可能快（多吃内存）**：专家缓存取 `min(可用物理内存 − 12 GB, 物理内存 × 0.6)`，上限 256 GB，配 `lfu`；**保存时按当时的可用内存再算一次**（手填的数字不动）。读不到内存或可用不足 8 GB 时，这个预设**不出现**，也不会编一个数字出来。
  - **省内存（少占内存）**：关掉专家缓存，显存放不下的专家全部就地读盘。
  - 手改任一项，预设标签自动变「自定义」；换机器/换内存状态后，已保存的数字仍按"正数 + LFU"识别为同一意图，不会误报「自定义」。
- **引擎自动值的上限说明写进界面：** `--ssd-cache` 留空的自动值 = 可用内存 − 12 GB，且**封顶 48 GB**；这就是大内存机器"内存只用了一半"的原因。

实机验收（256 GB 内存 / 2×RTX 3090 / DeepSeek-V4.1-Flash 2.00bpw）：内存池由 `auto` 的 48 GB（4672 槽，LRU）改为 153 GB（14893 槽，LFU）后，CPU 侧 13,897 个专家全部驻留内存（预载 107.9 GB / 31 秒），空闲读盘由 1.2 GB/s 降为 0 MB/s，生成速度 10.71 → 20.50 tok/s（+91%）。

验证：139 个 Python 测试、37 个 PowerShell 测试通过；`-ExpandAllSections` 实窗口加载确认控件、提示与预设标签渲染正确。**长对话与停止未做完整验收；Monitor 悬浮窗尚未在 dsv41 上实测。**
